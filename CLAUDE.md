# n8n-nodes-silverpoint — context for agents

Read [`specs/constitution.md`](specs/constitution.md) first. Binding, besides H-1..H-8:

- **N8N-Art. 1 — Zero run-time dependencies.** No `dependencies` in `package.json`; the engine is
  bundled at build time; `n8n-workflow` is a peer.
- **N8N-Art. 2 — A pure function of its input.** No service, no credential, nothing written but the
  output items.
- **N8N-Art. 3 — Verified-node rules from the first release.** `n8n-node lint` in strict mode (the
  default `eslint.config.mjs`, unchanged); published only from GitHub Actions with provenance.

Specs: `specs/prd.md` (N8N-REQ-001..011), `specs/technical-design.md`, `specs/tasks.md` (and the
ledger). `specs/spec-pack.md` is the pack from silverpoint's `changes/feature-007-bi-hosts/repositories/`.

Working rules:

- Test-first; tests are `test/*.test.mjs` (strict lint covers every `.ts` file, so tests stay `.mjs`)
  and cite the N8N-REQ they verify.
- `vendor/` is written only by `scripts/vendor.mjs`; `properties.generated.ts` only by
  `scripts/make-properties.mjs` (it applies n8n's lint fixes itself). `npm run check` verifies both.
- `nodes/Silverpoint/engine/` is generated by `scripts/bundle-engine.mjs` and not committed.
- Before committing: `npm run check && npm run build && npm test && npm run lint`.
